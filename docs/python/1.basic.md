# Python 基础语法
> Python 是一门解释型、弱类型、面向对象的高级编程语言，语法简洁易读，适合入门学习。

## 1. 注释
注释不会被程序执行，用于代码说明。
```python
# 单行注释：以 # 开头

"""
多行注释（文档字符串）
使用三个双引号包裹
"""

'''
也可以使用三个单引号
'''
```

## 2. 变量与数据类型
### 2.1 变量定义
Python 不需要声明变量类型，直接赋值即可。变量名规则：
- 只能由字母、数字、下划线组成
- 不能以数字开头
- 区分大小写
- 不能使用 Python 关键字（`if`、`for`、`def`等）

```python
name = "张三"
age = 18
height = 1.75
is_student = True
```

### 2.2 常用基础数据类型
| 类型 | 说明 | 示例 |
|---|---|---|
| `int` | 整数 | `10`, `-5` |
| `float` | 浮点数（小数） | `3.14` |
| `str` | 字符串，单/双引号 | `"python"` |
| `bool` | 布尔值，只有`True`/`False` | `True` |
| `None` | 空值 | `None` |

查看类型：`type()`
```python
print(type(age))
```

## 3. 输出与输入
### print() 输出
```python
print("Hello Python")
print(100)
# 多个内容用逗号分隔
print("姓名：", name)
# f-string 格式化（推荐）
print(f"年龄：{age}")
```

### input() 获取用户输入
> input 获取的内容**默认是字符串**，需要数字要手动转换
```python
user_input = input("请输入内容：")
num = int(input("请输入数字："))
```

## 4. 运算符
### 算术运算符
```python
a = 10
b = 3
print(a + b)  # 加 13
print(a - b)  # 减 7
print(a * b)  # 乘 30
print(a / b)  # 除 3.333...
print(a // b) # 整除 3
print(a % b)  # 取余 1
print(a ** b) # 幂运算 10^3=1000
```

### 比较运算符
结果是布尔值 `True` / `False`
```python
print(10 > 3)
print(10 == 10) # 等于（注意两个等号）
print(5 != 2)   # 不等于
```

### 逻辑运算符
`and`、`or`、`not`
```python
print(1 > 0 and 2 < 5)
print(1 > 10 or 2 < 5)
print(not True)
```

## 5. 条件判断 if
Python 使用**缩进**划分代码块（一般4个空格），缩进非常重要！
```python
age = 18
if age >= 18:
    print("成年人")
elif age > 12:
    print("青少年")
else:
    print("儿童")
```

## 6. 循环语句
### 6.1 while 循环
```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

### 6.2 for 循环
常搭配 `range()` 使用
```python
# range(起始,结束,步长)，结束数字不包含
for i in range(1, 6):
    print(i)

# 遍历字符串
for char in "python":
    print(char)
```

循环控制关键字：
- `break`：直接跳出整个循环
- `continue`：跳过本次循环，进入下一次

```python
for i in range(1,10):
    if i == 5:
        break
    print(i)
```

## 7. 容器类型
### 列表 list
有序、可修改，`[]`
```python
lst = [1, 2, "apple"]
lst.append(3)   # 添加元素
print(lst[0])   # 索引从0开始
lst[1] = 99
```

### 元组 tuple
有序、不可修改，`()`
```python
t = (1, 2, 3)
print(t[0])
```

### 字典 dict
键值对，key不可重复，`{}`
```python
dic = {"name":"张三", "age":18}
print(dic["name"])
dic["age"] = 20
```

### 集合 set
无序、元素不重复，`{}`
```python
s = {1,2,3,3}
print(s) # {1,2,3}
```

## 8. 函数 def
函数用于封装一段可重复调用的代码
```python
# 定义函数
def add(a, b):
    return a + b

# 调用函数
res = add(3,5)
print(res)
```
- `def` 关键字定义函数
- 参数写在括号内
- `return` 返回结果，没有 return 默认返回 `None`

## 9. 异常处理 try-except
捕获程序运行错误，防止程序直接崩溃
```python
try:
    num = int(input("输入数字："))
except ValueError:
    print("你输入的不是数字！")
```

## 10. 导入模块 import
Python 大量功能需要导入内置/第三方模块
```python
import math
print(math.sqrt(4))

# 导入指定函数
from math import pi
print(pi)
```

## 11. 基础编码规范
1. 缩进统一用4个空格，不要混用Tab
2. 语句末尾**不需要分号**
3. 一行尽量只写一条语句
4. 变量名推荐蛇形命名 `user_name`
5. 运算符两边建议加空格 `a = 1 + 2`

## 12. 简单综合示例
```python
"""
简易计算器：两数相加
"""
def calc_add():
    try:
        n1 = float(input("请输入第一个数字："))
        n2 = float(input("请输入第二个数字："))
        print(f"结果：{n1 + n2}")
    except:
        print("输入有误！")

if __name__ == "__main__":
    calc_add()
```
