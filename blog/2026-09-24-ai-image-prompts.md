```text

```

## 实用技巧

| 要点 | 说明 |
| --- | --- |
| 主体先行 | 先把最重要的内容写清楚，越具体越好 |
| 形容词 | 用颜色、质感、光线、情绪强化画面 |
| 画风词 | 写实摄影 / 二次元 / 水墨 / 油画 / 3D 渲染等 |
| 质量词 | 8k、高清、细节丰富、电影级 |
| 画幅比例 | `--ar 1:1` 方图、`--ar 3:4` 竖图、`--ar 16:9` 横图 |
| 负面提示词 | 告诉模型“不要什么”，比如：低质量、模糊、畸形手指 |

先记住公式，再按自己喜欢的画风叠加关键词，多试几次就能找到手感。
